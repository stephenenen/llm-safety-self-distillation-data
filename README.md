# llm-safety-self-distillation-data
This repository contains the datasets and supporting resources used in our research on self-distillation-based safety fine-tuning for large language models (LLMs). The released data include adversarial questions, benign questions, model responses, and refusal-oriented training samples generated using Llama and Qwen models.
The objective of this work is to investigate whether model-specific safety failures can be transformed into useful supervision for improving refusal robustness, while preserving helpfulness on benign queries.

## Overview
Our framework enables an LLM to improve its own safety behavior by identifying cases in which it inappropriately complies with adversarial requests and converting these failure cases into refusal-based supervision.

## Safety Notice
